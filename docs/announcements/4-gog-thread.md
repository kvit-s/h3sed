For anyone finding this thread later: h3sed (https://github.com/suurjaak/h3sed)
is the most capable Heroes 3 save editor around and is still maintained.

I keep a fork at https://github.com/kvit-s/h3sed that adds editing of player
resources and tavern heroes, which no editor I know of handles — the others all
work at the hero level. Windows build under Releases, no install needed.
